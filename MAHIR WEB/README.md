This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/bundled/bring_any_idea_to_life

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## 🚀 Overview

**MAHIR WEB** is not just a portfolio; it is a **Mission Control Center** designed to showcase complex digital artifacts. Built with a futuristic, dark-mode aesthetic, it serves as the central hub for **Web Applications**, **Trading Bots**, and **Crypto Mining Infrastructure**.

This system moves beyond static galleries by incorporating **Live Code Generation**, **GitHub Deep Scanning**, and **Real-time Preview Engines**.

---

## ✨ Key Features

### 🖥️ Holographic Interface
- **Glassmorphism Design**: Built on `Zinc-950` with deep backdrop blurs and neon signal accents.
- **Reactive Animations**: The Hero section features self-drawing wireframes that transform into solid icons representing *Trading*, *Mining*, and *Coding*.
- **CRT Effects**: Project cards feature authentic scanlines, signal noise, and sweeping laser effects on hover.

### 🛠️ The Deployment Manager (Admin Core)
A powerful, hidden GUI for managing your portfolio without needing a CMS or Database.
- **GitHub Deep Scan**: Simply paste a repository URL. The system connects to GitHub's API to:
  - Extrapolate a professional Title.
  - Analyze code composition to auto-generate Tags (e.g., "Python 60%", "React 40%").
  - Classify the project type (Web App vs. Bot vs. API).
- **Live Preview Sandbox**: See exactly how your project card will render before you commit.
- **Code Synthesis**: Instantly generates production-ready TypeScript configuration to add to your codebase.

### ⚡ Advanced Project Grid
- **Auto-Telemetry**: Projects display status badges (`LIVE`, `BETA`, `OFFLINE`).
- **Smart Thumbnails**: Automatically generates website screenshots using `thum.io` or accepts custom high-res uploads.
- **Tag Filtering**: Instant, smooth-scroll filtering by technology stack.

### 📂 Profile Dossier
- **Professional Bio**: A structured, military-style dossier displaying personal details suitable for high-level networking.
- **Asset Links**: Direct, stylized connections to Telegram (`@LUX_DOT`), GitHub, and Email.

## 📖 Usage Manual

### Adding a New Project

1. **Access Admin Mode**: 
   - Scroll to the footer of the website.
   - Click the button labeled **"MANAGER MODE"**.
   
2. **Input Data**:
   - **Method A (Fast)**: Paste a GitHub link into the scanner and click **Scan**. Review and accept the auto-generated data.
   - **Method B (Manual)**: Fill in the Title, Description, Link, and upload a custom cover image.

3. **Preview**:
   - Click **"GENERATE & PREVIEW"**. The card will appear in your browser immediately for testing.

4. **Deploy**:
   - The system will generate a code block on the right.
   - **Copy** the code.
   - Open `App.tsx` and paste it into the `PERMANENT_PROJECTS` array.
